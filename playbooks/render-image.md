# RENDER_IMAGE

在用户要求实际图片转换时读取本文件。主要交付物为图片，附简短的风格、版本和重要偏差说明。

1. 读取索引，确认候选 skill 的实现与验证状态；缺少能力时说明缺口，明确用户选择可复用创建或单次临时处理。
2. 区分内容图和风格参考图；仅有参考图时请求内容图。询问会明显影响画面的缺口，复用用户已给定的画法、保留范围与约束。
3. 填写 [StyleSpec](../shared/templates/style-spec.template.json)，说明低影响默认值。普通出图在规格充分且授权有效时直接执行。
4. 执行时才加载所选配方、渲染器及必要资产；核验真实工具、尺寸、输入角色、支持参数、授权和预算。只运行必要且已审查的代码。
5. 生成并检查实际图片。失败时记录原因，在授权预算和明确重试上限内修正；仍有问题时报告剩余缺口。
6. 允许本地记录时写入 [manifest](../shared/templates/run-manifest.template.json)。反馈默认只作用于当前图片，通用改动转入优化流程。

## 二进制数字绘画

- 正确处理来源方向、宽高比与透明度；采样明暗、轮廓及必要边缘信息。
- 使用字符大小、颜色、亮度或密度重建画面；主体和细节只由 `0`、`1` 字符组成。空白用于排版，背景允许纯色或透明，辉光遵循当前规格。
- 原照片仅作为采样输入，导出主体由字符层构成。`strict_01` 对中间表示或 SVG 文本层做字符集合检查，再检查最终图片；任意后处理后重新验证。
- 检查主体可辨识度、明暗层次、字形清晰度、尺寸和透明背景。记录随机种子、代码版本、环境和字体标识，复现范围限定为实际验证过的环境。

## 中国古典绘画与国风表达

- “国风”存在关键画法歧义时，以少量可见差异帮助选择：淡墨留白、精细线条与设色、白描线条、透明水彩晕染等。
- 只改画法的任务保留原人物、衣着、物体、构图和场景；内容替换需明确许可。
- 真实绘画重构优先使用已获准且支持图像输入或编辑的模型。纯代码近似需说明可达到的效果并取得认可。
- 将内部强度等字段映射为真实支持的接口参数；服务身份、外传、预算与保留政策按证据记录。

执行前检查文件类型、文件大小、像素数量及输出路径；SVG 等主动格式先进行安全处理。缺少运行或生图能力时交付已完成的规格或代码，并明确图片尚未生成或验证。
