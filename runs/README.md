# 本地运行目录

每次需要保存的任务使用独立的 `runs/<task-id>/`，其中可包含 `style-spec.json`、`manifest.json`、内容图、参考图、输出图及私人反馈。使用 [任务模板](../shared/templates/README.md) 填写记录。

本目录只有本说明进入版本库。根目录 `inputs/`、`outputs/` 和 `private/` 同样由 Git 忽略，按实际任务需要创建。

任务结束后，向用户说明输出位置和本地保存范围。清理时先确认目标任务及需要保留的成果，再删除对应的本地任务目录；清理范围以有权限操作的本地文件为准。宿主或外部服务的留存情况按其实际政策与操作结果说明。

用于长期评测或公共展示的图片须有对应用途授权；确认后单独迁移到指定测试资产位置，并记录来源和许可。
