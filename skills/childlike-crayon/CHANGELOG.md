# Changelog

本文件记录版本历史。当前执行规则见 [入口](SKILL.md)；源码恢复沿用本 skill 的独立依赖与 `runs/` 边界。

## 独立包维护 — 2026-10-02

- 明确执行资料、依赖与缓存的本地边界；绘画提示词、等级规则、执行代码与版本保持原样。
- 旧版本指向原项目任务资料的回退说明按实际删除状态修正。

## 0.2.5（候选）— 2026-10-02

- 输入副本、输出、规格、日志和快照统一保存到本 skill 的 runs/；相对输出及校验路径按 skill 目录解析。
- 校验拒绝越出 skill 的路径；回归覆盖其他工作目录调用、绝对外部路径与符号链接。
- 用户要求清理旧项目级运行资料；历史章节中的样图、日志和回退快照留存描述按此次清理状态更新。

## 0.2.4（候选）— 2026-10-02

- 按用户明确反馈，出图前先询问低、中、高档并等待答复；中档为推荐选项，用户明确采用默认档时使用中档。
- 缺少档位时，准备脚本与演示入口返回 `awaiting_drawing_level`，保留等待状态；输入规范化与任务输出在明确选择后执行。
- 默认只生成一张、调用一次图像工具，自动重试次数改为 0；质量偏差随候选交付，后续生成由用户明确提出。
- 同步规范、StyleSpec、索引、运行元数据和回归用例；验证范围见 [验证记录](references/validation.md)。
- 当时的 0.2.3 快照与任务记录已清理，现保留验证摘要。
