# 儿童蜡笔画约定

版本：0.2.5。范围：naive-source-colors 通用配方。所有内容使用同一套视觉结构分析和绘画能力规则；具体元素来自当前输入与用户要求。

## 统一处理原则

观察核心视觉结构、形状轮廓、相对比例、空间布局、遮挡层次、主色关系、信息密度与识别线索，据此确定核心保留项及可概括区域。核心内容可以由整体组织或多个元素共同形成。保留关键分组、重复关系、视觉层次和留白；简化强度随所选等级作用于整个画面。

入口、规范、提示词、参数与演示均使用内容无关的规则。禁止预置单一使用用例，禁止按题材分类选择 if/else 配方，禁止从历史任务推定当前元素、构图或颜色。任务笔记仅描述本次内容及明确要求；各次运行相互独立。

## 三档绘画能力

| 等级 | 细节质量 | 笔画表现 |
| --- | --- | --- |
| 低 low | 核心结构由少量歪斜大形状和极少辨识笔画表达；次要区域为粗略色团及可辨轮廓，内部细节大幅省略，附带文字为不可读涂痕或留白 | 控制力弱，轮廓断续、接合粗糙、比例不稳、涂色出界明显 |
| 中 medium，推荐 | 基本结构可辨，细节近似、粗简，局部错位和遗漏，附带文字为残缺痕迹 | 有限控制，线条犹豫、歪斜，局部轮廓断开 |
| 高 high | 保留更多辨识特征、内部结构和有限明暗，附带文字可保留较可辨的手写内容 | 控制力较好，轮廓较完整，保持稚拙形状与粗蜡笔颗粒 |

等级同时控制准确度、完整度、笔画控制力、形状复杂度和细节数量。所有档位保持正常分辨率、清晰纸纹与蜡笔颗粒。低档允许粗略轮廓和高低变化可辨，核心要求是内部细节充分概括与笔画粗拙。

收到出图请求后，用户已明确指定等级则直接沿用；尚未指定时先反问低、中、高档并等待用户明确回答，中档作为推荐选项。普通“画图”“直接出图”要求仍需完成选择；异步预选、等待超时、尚未回复或流程无法交互时保持 `awaiting_drawing_level`。用户明确采用默认档时映射为中档。各次运行用 `drawing_level` 记录选择，同一张图的修改沿用其等级。

## 保留与简化

| 维度 | 通用规则 |
| --- | --- |
| 核心内容 | 保留关键视觉结构、识别线索和用户明确要求 |
| 构图 | 保留相对比例、位置、分组、遮挡、重复关系及主要留白 |
| 次要内容 | 随等级降低合并密集细碎结构，使用大形状和粗略色块表达 |
| 配色 | 沿用原图主色关系，减少色阶，以平涂和叠涂表达 |
| 附带文字 | 低档不可读涂痕或留白；中档残缺痕迹；高档可辨手写内容；用户明确要求单独记录 |
| 媒介 | 粗笔触、颗粒露纸、压力变化、叠涂和涂色出界 |
| 输出 | 一张 PNG，原图宽高比，浅色纸面 |

每次出图请求默认只调用一次图像生成工具、输出一张，自动重试次数为 0。技术或视觉偏差如实报告，可查看结果按候选交付；后续生成由用户明确提出修改、重画或追加图片后执行，按其授权数量处理。

任务笔记只列核心结构、空间关系、主色与明确要求。低档省略附带文字原文和逐项细部清单，保留关键分组及整体组织。用户明确要求与等级默认值冲突时，明确相应内容的取舍。

## 验收

分别检查核心结构与构图、主色、形状简化、细节准确度与完整度、笔画控制、次要区域概括、文字及蜡笔媒介。低档存在精细内部构造、密集规则细部、精确轮廓、写实光影或可读附带文字时，相应条目记为 fail；任一硬约束失败则整体失败。粗略外形可辨本身符合低档规则。

技术检查、Agent 视觉检查与用户验收分别记录。实际能力边界见 [验证记录](validation.md)，每次输出按当前输入检查。输入、输出与任务资料留在本次运行目录；长期评测、训练及公开展示按对应授权处理。
