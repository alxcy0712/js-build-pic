# 儿童蜡笔画约定

版本：0.3.3。范围：naive-source-colors 通用配方。所有输入采用相同的内容分析、取舍和重绘流程，规则依据视觉信息的作用组织。

## 信息的作用

**核心信息**承担画面的主要含义、身份辨识、关键结构、空间关系、构图或主色组织；用户明确要求保留的信息也进入核心范围。每项说明其原图位置以及移除后会改变的核心表达，按所选档位确定最低充分画法。

逐主要部分将可见信息拆成**结构基底**与**附属丰富度**。结构基底包含承担当前原图组成方式的外部轮廓、内部关键分区、连接与接触、开口与间隙，以及重复结构的排列节奏；这些作用进入核心的最低充分表达。附属丰富度包含可独立减少的表面变化、装饰和精细构造，按可选细节判断。同一元素可同时提供这两类信息，分别记录其作用和画法。

**可选细节**是移除后仍保有核心表达的附属信息。通过移除测试检查其作用：移除后主要含义、辨识、结构、构图和主色关系仍成立，该信息可作为细节候选。细节优先级由其对特征辨识、表达完整度和视觉层次的贡献决定；面积、位置与视觉显著性提供辅助证据。重要度根据当前内容与用户意图判断。

**细节组**是可独立取舍、承担同一作用的一组附属信息。重复微观信息按功能与区域成组；独立作用分别分析。单项移除与成组移除均需检查，多个信息共同承担核心作用时保留其最低充分组合。分析颗粒度围绕视觉作用保持一致，同一内容的档位对照沿用相同分组。

分组后同时移除全部可选组，再逐主要部分对照原图检查。检查目标包括原图中主体的组成方式、内部组织、相互连接和重复节奏；类别可辨只是其中一项证据。结构作用丢失时，将最低充分线索归入核心，附属丰富度继续按预算取舍。重复结构可用更少的粗略标记概括，其排列关系和作用应可辨；核心数量或精确关系承载字义、功能或用户要求时按其计划保留。

复杂输入按主要部分、空间层次与遮挡逐区观察，沿同一流程记录可见证据。先核对轮廓、分区和连接，再分析局部丰富度；信息密度由成组色区与重复节奏概括。主要部分的最低表达建立在可见证据上，遮挡关系按原图组织。

文字和符号按作用进入核心信息或可选细节，使用与该作用相符的保留规则。决定核心含义或用户明确要求的内容按核心计划表达；其余内容随细节选择和档位概括。

## 分步判断流程

先查看原图，再逐步完成以下阶段；每阶段回看图片核对后继续，将简短结论保存到 [分析模板](analysis.template.json)。

| 阶段 | 字段 | 完成条件 |
| --- | --- | --- |
| 观察 | observation | 记录主要组织、相对位置、遮挡、主色和留白；整体笔记保持宏观信息 |
| 判断作用 | core_information、optional_details、grouping_check | 每项有原图证据；逐主要部分拆分结构基底与附属丰富度；全部可选组移除后的最低结构已对照原图核对；附属组按贡献降序排列 |
| 制定计划 | 各项 depiction、可选项 action、plan_check | 核心采用最低充分画法；可选细节按预算从高贡献开始选择；计划对照原图、档位与用户要求完成检查 |
| 执行与验收 | scene.txt、prompt.txt、visual-review.json | 生成按计划执行；成图逐项核对核心、选中细节和省略细节，画法单独验收 |

`source` 写入原图中的位置与观察到的信息类型；附属文字只记录区域与类型，核心文字按其含义或明确要求记录。`role` 说明核心信息承担的作用。`importance` 说明可选细节对整体的贡献及排序依据。`depiction` 只写该项在当前档位实际采用的画法。

可选项的 `action` 为 `retain`（保留该特征）、`simplify`（概括该特征）或 `omit`（省略该特征）；保留与概括均计为选中的细节组，省略项的 `depiction` 留空。选中项形成重要度列表的前段，后段统一省略。`optional_details` 可为空，表示原图分析得到的可选细节组为零。

`guide_marks` 按 [数据格式](guide-format.md) 表达核心和选中项的最低充分形状、色区与辨识笔画，省略项使用空数组。`grouping_check` 记录逐主要部分的结构基底、共同作用及全部可选组移除后的检查结论；`plan_check` 记录对原图、核心参考稿、完整计划参考稿、取舍和用户要求的核对结论。每个选中组在 `depiction` 与 `guide_marks` 中指定可独立核对的粗略可见线索。在正常输出尺寸及关键局部中，该线索应与邻接色区、露纸和随机颗粒区分。细小或低对比度信息通过已允许的局部夸张和粗略形状概括表达；对照核心与完整参考稿核对其可见性及遮挡。各核心项沿既定最低表达执行，其余内部与表面丰富度由选中可选组提供。

分析记录只保存可复核结论和简短证据。原图证据不足时回看对应区域；同等级硬约束冲突时取得用户取舍后继续。

入口、规范、提示词和模板均保持内容无关，具体内容仅进入当前任务资料。题材标签、历史输入和固定物件清单均不能作为本次判断依据。

## 三档保留量与画法

| 等级 | 可选细节组目标 | 核心与画法 |
| --- | --- | --- |
| 低 low | 0–10% | 核心内外结构由少量歪斜形状、成组色块和最低辨识笔画表达；关键分区与连接可辨，周围留空，接合粗糙、出界明显 |
| 中 medium，推荐 | 约 50% | 核心清楚，选中细节粗简近似；线条犹豫断续、局部错位、接合与内部结构有概括和残缺 |
| 高 high | 约 80% | 核心清楚，选中细节较完整；保留歪斜、不对称、粗笔触与简化的明暗，缩略图下仍呈现儿童造型 |

准备脚本按可选细节组数量确定计划预算：中、高档取最接近目标比例的整数个组；低档最多保留向下取整的 10%，允许全部省略。组数较少时实际计划比例受整数舍入影响，运行记录保存总组数、选中组数和真实计划比例。原图已有的复杂度决定分析分组；画面可选细节为空时直接使用核心计划。

该比例用于准备阶段的细节选择，图像模型的实际保留效果由视觉检查验证。画法的准确度、完整度和笔画控制分别检查；核心和选中细节都可以用稚拙笔画表达。所有档位保持正常图片分辨率、清晰纸纹与粗蜡笔颗粒。

三档均保护主要部分的最低内外结构。低档以平涂、粗略轮廓和稀疏结构笔画表达，整体组织、重复关系与高低变化保持可辨；中档加入选中的少量附属线索；高档允许更多附属特征与粗略明暗，同时保持明显儿童造型。选中可选文字在低档为非文字符号或留白，中档为残缺痕迹，高档可为较可辨的手写内容；核心文字按其计划保住含义。

收到出图请求后沿用明确档位；缺少选择时询问并等待明确回答，中档为推荐项。普通出图要求、异步预选和超时均保持等待；用户明确采用默认档时映射为中档。同一张图修改沿用选择，新的明确选择优先。

## 生成边界

主要比例、位置、分组、遮挡、重复关系、主色与留白保持对应，形状和色阶随档位概括。背景与主体按信息作用和细节预算处理；已有空白保持空白。用户明确要求优先，核心内容采用符合档位的最低充分表达。

脚本分别绘制核心参考稿与核心加选中项的计划参考稿，后者作为唯一生成图像输入。省略项的源图证据与判断保存在当前分析文件。宏观观察保持主要组织和色彩关系，所有具体辨识笔画沿逐项计划进入参考稿。准备检查验证记录结构、选择顺序、数量和形状数据；Agent 先将核心参考稿直接对照原图核对最低内外结构，再检查计划参考稿的可选信息、遮挡与留白。模型可依据常见形象补充结构，实际成图仍须逐项验收。

每次请求默认一张、图像工具调用一次、自动重试为 0。可查看结果作为候选交付，偏差如实报告；用户明确提出后续生成时按其授权数量执行。

## 逐项验收

先检查完整构图，再查看缩略图和关键局部，逐项核对原图、分析计划与成图：

- 直接对照原图逐主要部分检查外部与内部最低结构、分区、连接和重复组织，填写 `source_structure_and_minimum_cues`；核心计划自身删减过度使此项失败。核心项再逐项记录其计划含义和关系的证据。
- 选中细节按计划的保留或概括方式出现，省略项达到省略目标；额外恢复的细部逐项记录。逐组填写实际出现情况，固定组清单内的出现比例由 `review` 计算；无法判断的组保持 `uncertain`，比例保持空值。原图中组的成员、位置与可核对特征写入证据，数量与画法分别评审。
- 重要度判断与原图作用相符，关键贡献优先保住，计划选择顺序合理。
- 细节数量、准确度、完整度和笔画控制符合档位；低档内部稀疏，中档粗简，高档较完整。
- 缩略图下形状具有明显稚拙感；完整轮廓与细部都符合所选画法。
- 背景与文字按作用和档位处理；核心信息采用最低充分表达，可选内容按取舍计划表达。
- 主色、留白、蜡笔颗粒、露纸、叠涂和出界符合要求；非预期内容和结构错误逐项检查。

原图最低结构遗漏、核心计划删减过度、选中细节过度恢复、低档精细内部构造或写实光影、超出计划的可读附属文字，以及各档成人般工整造型，均使对应视觉硬约束失败。任一适用硬约束失败即整体失败；证据不足保持 `not_run`。技术检查、Agent 视觉评审和用户验收分别记录。

图片与记录保存在当前任务的忽略目录，长期评测、训练和公开展示按各自授权执行。实际能力边界见 [验证记录](validation.md)。

## 维护验证

每轮使用新建或本轮授权输入，按核心辨识与文字、空间组织与遮挡、主色与留白、重复与密度、细节选择与实际省略、画法与媒介、独立执行组织覆盖。开发输入与保留验收输入分开；候选冻结后完成三档和不同结构复杂度的检查。实验开始时记录阶段、图像调用上限与停止条件，每项任务保留单张与零自动重试。验收失败记录为失败，调优后的候选使用新的保留输入。

Git 交付文件承载跨任务能力。运行资料仅用于当前验证，经验维护在已有规范、代码和验证记录中。回退以 Git 版本为依据；稳定版替换与用户效果确认分别记录。独立验证按 Git 文件清单构建项目外副本，全新安装，真实执行，并在清理当次产物后用新输入再走完整入口。
