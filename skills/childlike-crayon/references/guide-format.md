# 绘制参考稿数据

`guide_marks` 将当前任务的最低充分画法转成通用形状。Agent 查看原图后确定位置、颜色、遮挡和辨识笔画，脚本仅负责按计划绘制。参考稿承载本次可见信息，原图承载观察与验收证据。

坐标按归正后的原图归一化为 0–1：左上为 `[0, 0]`，右下为 `[1, 1]`。核心项和选中可选组各自提供至少一个形状；省略组的 `guide_marks` 为 `[]`。先绘制核心项，再按重要度绘制选中组；数组内部顺序决定覆盖关系。核对参考稿时检查遮挡是否仍保护核心。

| type | 位置字段 | 用途 |
| --- | --- | --- |
| rect | box: `[x, y, width, height]` | 大色区与矩形结构 |
| ellipse | box: `[x, y, width, height]` | 圆形与椭圆形色区 |
| polygon | points: `[[x, y], …]`，至少3点 | 轮廓与不规则色区 |
| line | points: `[[x, y], …]`，至少2点 | 辨识笔画与线性关系 |

面积形状使用 `fill`；轮廓和线使用 `stroke` 与 `width`。颜色为六位十六进制色值或 `none`；线宽相对画布短边，范围 `(0, 1]`。全部坐标落在画布内。每项最多200个形状，单个线或多边形最多128点，全图最多1000个形状。文本字义写入当前项的 `depiction`，其区域和最低辨识笔画用上述形状表达。渲染器使用锁定的 sharp，将经过数字、形状和颜色校验的 SVG 直接栅格化；字体、外部文件和外部 URL 依赖为零。

例如，一个当前任务中的色区可以写为：

```json
{ "type": "polygon", "points": [[0.2, 0.3], [0.55, 0.32], [0.5, 0.6]], "fill": "#ad6842", "stroke": "#563e2a", "width": 0.008 }
```

`core-reference.png` 仅包含核心形状。先将其直接对照原图，逐主要部分检查最低内外结构、分区、连接、间隙和重复节奏；全部可选组移除后，原图的主要组成方式保持可辨。结构作用丢失时修订核心分组与最低画法。再核对 `plan-reference.png` 中选中项的辨识、遮挡和附属信息取舍，以及主要比例、位置、颜色与留白。选中组的粗略线索需与其邻接色区、露纸及随机颗粒可区分；从核心参考稿到完整参考稿的新增表达可逐组核对，细小或低对比度笔画可按已允许的局部夸张概括。修订分析后使用新的渲染目录准备。实际生成以 `plan-reference.png` 为唯一图像输入；核心参考稿和完整原图用于 Agent 对照检查。
