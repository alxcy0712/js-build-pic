# 参考稿设计与风格确认单

日期：2026-10-06。候选：0.5.0；已发布基线：0.4.0 / 项目v1.1.0，Git `0326cbda0e169dd54b3ecec15b3707e3698508a2`。

用户已明确采纳“把内容重要度与绘制顺序分别表达”和“小范围独立开发蜡笔画法机制”，要求从本项目出发独立设计。该授权覆盖下表实施与适当验证。0.4.0外部回归的效果已获用户认可，适用范围见[验证记录](validation.md)。

2026-10-08用户明确要求“合并到主分支，推送”，授权将本次0.5.0候选作为main当前实现。版本保持draft，用户视觉验收及严格取舍的实测范围继续按验证记录维护。

| 项目 | 本次确认范围与验收 |
| --- | --- |
| 内容与层次 | 语义作用控制取舍，`draw_order` 控制原图从后到前的覆盖。回归检验后方辅助项、核心开口和真实前景遮挡。 |
| 画法作用层 | 完整计划参考稿承载蜡笔机制；核心参考稿保持平涂，便于结构核对。原图为最终生成的第一内容依据，完整计划稿为第二辅助图。 |
| 粗钝轮廓 | 本项目编写的短二次曲线与圆笔端，宽度轻微变化；原形状顶点、线端点和连接位置固定。中段偏移受线宽及段长约束。 |
| 往返叠涂 | 在局部形状内裁切交替方向的宽笔画，以少量透明度变化形成同主色的叠涂；笔宽依据局部短边，两档分别采用7.5%和5.5%的参考宽度。 |
| 局部露纸 | 纸面短线沿填色笔画出现，形状底层以不透明纸色覆盖后方内容；关键辨识线连续可读，开口与接触单独核对。 |
| 可复现性 | `crayon-guide-v1`，默认代码seed `20261006`，逐形状按 `draw_order` 派生随机序列。清单 `guide_rendering` 记录画法、档位与seed；`execution.seed` 单独记录模型实际返回值。 |
| 颜色与结构 | 所有色值来自当前原图分析或已确认原图主色；轮廓、部件、遮挡与必要开口按原图保护。代码回归和实际目视检查分别记录。 |
| 对照方法 | 同一自制内容图、相同档位、几何与提示词，比较排序后的平涂参考稿与蜡笔参考稿。分别检查参考稿与真实模型成图；单次模型差异只支持该次观察。 |
| 回退 | 旧版本按上述Git提交恢复完整skill，并保护当前未提交修改；旧运行使用对应Git入口。独立包自带代码、资料与锁定依赖。 |

本实现仅增加参考稿画法。图像模型继续承担最终风格重绘；单张、一次调用、零自动重试、两档共享核心、文字隔离、生成原件保存与导出沿用既有约定。评测按预先命名的两档任务执行，各任务分别准备与验收。

研究启发与具体关联见[来源](sources.md)。本项目独立编写上述机制与回归，生产资源由本目录的代码、资料与锁定依赖组成。
