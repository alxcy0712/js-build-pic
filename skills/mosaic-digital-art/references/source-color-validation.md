## 用户确认与实现范围

用户明确要求通用 skill 使用原图颜色，并要求每个 skill 文件夹可以独立完整运行。当前默认采用 `source-color-grid`，每格记录并使用采样 RGB；原色模式 gamma 为 1。底色默认取来源边缘颜色，有采样透明度时使用透明底。旧版绿色效果通过显式 `--color-mode green` 保留。

每个 skill 文件夹自带依赖清单、锁文件、模板、脚本、测试、演示及引用资料。此包需要 Node.js 20.9.0 及以上和 npm；安装依赖后可独立进行本地出图与验证。运行说明见 [Skill 入口](../SKILL.md)。

隔离检查清除了 `NODE_PATH` 和 `NODE_OPTIONS`，复制时排除 `node_modules`、缓存和已有运行结果，并先检查目录内 Markdown 引用与符号链接。当前实测环境为 macOS ARM64、Node.js `24.19.0`、sharp `0.35.5`、libvips `8.18.7`。安装后，演示输入由随包脚本在本地生成。

目录迁移检查曾复现测试 CLI 将空格、中文路径保留为 URL 编码导致脚本加载失败的问题；改用 `fileURLToPath` 后 15 项测试与演示通过。CLI 回归同时从独立工作目录执行，使用带空格和中文的输入路径。单独使用时，所用 Agent 读取本目录的 `SKILL.md` 获取完整步骤；其他 Agent 产品与操作系统尚待实际接入验证。隔离验证在副本中运行 `npm ci --ignore-scripts --cache .cache/npm`、`npm test` 和 `npm run demo`，日志保存在该副本的 `runs/`。

在视觉检查中发现高对比边缘的插值过冲，原色采样改用线性核并加入颜色范围回归。半透明取色采用浮点处理；颜色配置先归一再采样。绿色模式沿用旧采样路径用于兼容。

原图色彩保留到采样区域粒度，细于网格的纹理由该区域的代表色概括。字符之间露出纯色底，因此整体亮度和饱和度感受还受字形覆盖率影响。
